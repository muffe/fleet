For fleet-wide dry runs, status checks, or explicitly requested configuration syncs, read [.agents/skills/fleet/SKILL.md](.agents/skills/fleet/SKILL.md). The default scope is every machine in the local, ignored `machines.json`, dispatched concurrently through T3 Code. Use `machines.example.json` to set up a new fleet. Local skills are selected in ignored `skills.local.json`. `scripts/install.py` is the per-machine engine.
